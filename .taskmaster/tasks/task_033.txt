This task involves implementing advanced blend modes to improve the monochrome image rendering in the duo-chrome application. The initial implementation has already changed the blend mode from 'multiply' to 'destination-in' in the createMonochromeImage function:

1. **Research and Selection of Blend Modes**:
   - Research p5.js supported blend modes (BLEND, ADD, MULTIPLY, SCREEN, OVERLAY, HARD_LIGHT, SOFT_LIGHT, DODGE, BURN, etc.)
   - Research CSS/Canvas blend modes like 'destination-in' which uses the image as a mask
   - Analyze which blend modes work best with monochrome imagery
   - Document the visual characteristics of each blend mode with monochrome content

2. **Implementation of Blend Mode System**:
   ```javascript
   // Example implementation of blend mode selection
   function applyBlendMode(graphics, mode) {
     switch(mode) {
       case 'multiply':
         graphics.blendMode(MULTIPLY);
         break;
       case 'screen':
         graphics.blendMode(SCREEN);
         break;
       case 'overlay':
         graphics.blendMode(OVERLAY);
         break;
       case 'destination-in':
         // Special handling for CSS/Canvas blend modes
         // This mode uses the image as a mask, only keeping parts where source and destination overlap
         graphics.blendMode('destination-in');
         break;
       // Add more blend modes as needed
       default:
         graphics.blendMode(BLEND);
     }
   }
   ```
