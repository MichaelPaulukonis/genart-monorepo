- `expandTargetGuiPanel(panelTitle)` - Expand specific panel by title
- `setDrawingMode(mode)` - Select from dropdown
- `setPaintMode(mode, target)` - Set fill/outline paint mode
- `setParameter(parameter, value)` - Adjust any parameter input
- `clickGuiButton(buttonText)` - Click button by value attribute
- `getParameterValue(parameter)` - Read current parameter value
- `clearCanvas()` - Click clear button with force option

### Test Patterns

**Smoke Test Pattern:**
```javascript
test('description', async ({ page }) => {
  await page.goto('/')
  await waitForFontsLoaded(page)
  await waitForP5Ready(page)
  const canvas = page.locator('canvas').first()
  await expect(canvas).toBeVisible()
  // Verify dimensions, styles, interactivity
})
```

**Drawing Mode Test Pattern:**
```javascript
test.beforeEach(async ({ page }) => {
  const consoleErrors = setupConsoleErrorTracking(page)
  await page.goto('/')
  await waitForP5Ready(page)
  await page.evaluate(({ settings, text }) => {
    window.setPolychromeParams(settings)
    window.setPolychromeText(text)
  }, { settings, text })
})

test('renders pattern', async ({ page }) => {
  const canvas = page.locator('canvas').first()
  await simulatePaintGesture(canvas, page, [[{x:50,y:50}, {x:200,y:100}]])
  await page.waitForTimeout(500)
  expect(await canvasHasContent(page)).toBe(true)
  await expect(canvas).toHaveScreenshot('name.png', { maxDiffPixelRatio: 0.1 })
})
```

- Screenshots stored in `*.spec.js-snapshots/` directories

- Configurable tolerance: `maxDiffPixelRatio: 0.1` (10% difference allowed)
