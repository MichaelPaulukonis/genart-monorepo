# Title: Add Source Image Display Feature for Crude-Collage-Painter
# Status: pending
# Dependencies: 30
# Priority: medium
# Description: Implement functionality to show the source image on-screen in the crude-collage-painter app, either as a small overlay/thumbnail, side panel, or toggle view, to help users reference the original image while painting.
# Details:
Implement a source image display feature for crude-collage-painter with the following components:

1. **Display Options Analysis & Implementation**:
   - Implement a toggleable image display with multiple view options:
     - Thumbnail overlay in corner (non-intrusive)
     - Side-by-side panel view (split screen)
     - Toggle view (switch between source and canvas)
   - Make the view mode configurable via keyboard shortcut
   ```javascript
   function keyPressed() {
     if (key === 'v') {
       // Cycle through view modes: overlay → side panel → toggle → overlay
       currentViewMode = (currentViewMode + 1) % 3;
       updateSourceImageDisplay();
     } else if (key === 'h') {
       // Toggle visibility
       sourceImageVisible = !sourceImageVisible;
       updateSourceImageDisplay();
     }
   }
   ```

2. **Image Loading & Handling**:
   - Ensure source image is loaded efficiently and cached
   - Handle proper scaling while preserving aspect ratio
   - Add opacity controls for overlay mode
   ```javascript
   function displaySourceImage() {
     if (!sourceImageVisible) return;
     
     switch(currentViewMode) {
       case 0: // Overlay
         push();
         tint(255, overlayOpacity);
         image(sourceImg, width-thumbnailWidth-10, 10, thumbnailWidth, thumbnailHeight);
         pop();
         break;
       case 1: // Side panel
         // Resize canvas layout to accommodate side panel
         image(sourceImg, canvasWidth, 0, panelWidth, height);
         break;
       case 2: // Toggle
         if (showingSourceImage) {
           image(sourceImg, 0, 0, width, height);
         }
         break;
     }
   }
   ```

3. **UI Controls & Indicators**:
   - Add small UI indicators showing current view mode
   - Implement slider for opacity control in overlay mode
   - Add visual border/frame around source image for clarity

4. **Performance Optimization**:
   - Ensure the feature doesn't impact painting performance
   - Implement efficient image scaling for thumbnails
   - Consider lower resolution preview for performance if needed
