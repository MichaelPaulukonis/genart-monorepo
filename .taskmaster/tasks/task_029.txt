# Title: Implement Automated Version Management System for Monorepo Apps
# Status: done
# Dependencies: 18, 21
# Priority: medium
# Description: Create a system to automatically increment version numbers across all apps in the monorepo, updating the version field in each app's package.json file according to semantic versioning principles.
# Details:
This task involves implementing an automated version management system for all applications in the monorepo:

1. **Version Management Strategy**:
   - Implement semantic versioning (MAJOR.MINOR.PATCH) across all apps
   - Update only apps that have actual changes (not all apps every time)
   - Use standard npm versioning commands (`npm version patch|minor|major`)
   - Define policies for when to increment each version component

2. **Nx Integration for Change Detection**:
   - Leverage Nx's affected detection to identify which apps have changes
   - Use `nx affected:apps` to determine which apps need version bumps
   - Create a simple script that:
     - Detects affected apps using Nx commands
     - Runs appropriate npm version commands in each affected app directory
     - Commits version changes
   
   ```javascript
   // Example implementation in version-update.js
   const { execSync } = require('child_process');
   
   function updateVersions(versionBump = 'patch') {
     // Get affected apps using Nx
     const affectedOutput = execSync('npx nx affected:apps').toString();
     const affectedApps = affectedOutput.trim().split('\n');
     
     if (affectedApps.length === 0 || (affectedApps.length === 1 && !affectedApps[0])) {
       console.log('No affected apps detected. Skipping version updates.');
       return;
     }
     
     console.log(`Updating versions for affected apps: ${affectedApps.join(', ')}`);
     
     // Update version for each affected app
     affectedApps.forEach(appName => {
       const appPath = `apps/${appName}`;
       console.log(`Updating ${appName} with npm version ${versionBump}`);
       try {
         execSync(`cd ${appPath} && npm version ${versionBump} --no-git-tag-version`);
       } catch (error) {
         console.error(`Error updating version for ${appName}:`, error.message);
       }
     });
     
     // Optionally commit changes
     console.log('Version updates complete. Remember to commit the changes.');
   }
   
   // Parse command line arguments
   const args = process.argv.slice(2);
   const versionBump = args[0] || 'patch';
   updateVersions(versionBump);
   ```

3. **Integration with Build/Release Process**:
   - Add an Nx target for version management in workspace.json
   - Create npm scripts for version bumping (patch, minor, major)
   - Integrate version update into the CI/CD pipeline
   - Ensure version updates trigger appropriate rebuilds

4. **Nx Configuration**:
   ```json
   // Example addition to workspace.json or nx.json
   {
     "targets": {
       "version": {
         "executor": "@nrwl/workspace:run-commands",
         "options": {
           "command": "node tools/scripts/version-update.js"
         }
       }
     }
   }
   ```

5. **Git Integration**:
   - Add capability to automatically commit version changes
   - Optionally create git tags for releases
   - Ensure version changes are committed with appropriate messages

6. **Documentation**:
   - Document the versioning strategy for developers
   - Create usage examples for version bumping
   - Document integration with CI/CD processes
   - Explain how the affected detection works with versioning

7. **Error Handling and Validation**:
   - Implement comprehensive error handling for all operations
   - Validate version formats and changes before applying
   - Provide clear error messages and recovery options

8. **Manual Override Capabilities**:
   - Support forced version updates regardless of detected changes
   - Allow specifying specific apps for version updates
   - Provide options to bypass normal version increment rules
