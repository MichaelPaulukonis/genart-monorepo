   ```html
         <li><strong>h/i</strong>: Toggle this help screen</li>
       </ul>
       
       <h3>Composition Modes</h3>

         <li><strong>Mode 1</strong>: [Description of mode 1]</li>

     </div>
   </div>
   ```

   ```css
   .help-overlay {

     display: none;
   }
   ```

3. Implement JavaScript functionality to toggle the help overlay:
   ```javascript
   function keyPressed() {
     // Existing key handlers...
     
     // Add help toggle functionality
     if (key === 'h' || key === 'H' || key === 'i' || key === 'I') {
       toggleHelpOverlay();
     }
   }
   
   function toggleHelpOverlay() {
     const helpOverlay = document.getElementById('help-overlay');
     helpOverlay.classList.toggle('hidden');
   }
   ```

4. Ensure the help overlay content accurately describes all available keyboard shortcuts and composition modes in the computational-collage app.

5. Make sure the overlay is responsive and displays correctly on different screen sizes.

6. Add a small help icon in the corner of the UI that users can click to toggle the help overlay as an alternative to keyboard shortcuts.

7. Consider adding a "Click anywhere to close" message at the bottom of the help overlay and implement the corresponding functionality:
   ```javascript
   document.getElementById('help-overlay').addEventListener('click', function(event) {
   ```
