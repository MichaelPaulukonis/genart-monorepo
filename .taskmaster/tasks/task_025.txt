# Title: Implement Random Seed URL Parameters for Deterministic Art Generation
# Status: deferred
# Dependencies: 15, 18
# Priority: medium
# Description: Add URL parameter support for random seeds in generative art apps to enable deterministic output, allowing users to bookmark specific compositions and enabling reliable visual regression testing.
# Details:
This task involves implementing a random seed mechanism across the p5.js applications, starting with duo-chrome:

1. **Add URL Parameter Support**:
   ```javascript
   // In setup() function
   function setup() {
     // Get seed from URL if present
     const params = new URLSearchParams(window.location.search);
     let seed = params.get('seed');
     
     // If no seed provided, generate a random one
     if (!seed) {
       seed = Math.floor(Math.random() * 1000000);
       // Update URL without reloading page
       const newUrl = new URL(window.location);
       newUrl.searchParams.set('seed', seed);
       window.history.pushState({}, '', newUrl);
     }
     
     // Apply the seed to p5.js random functions
     randomSeed(parseInt(seed));
     noiseSeed(parseInt(seed));
     
     // Rest of setup code...
   }
   ```
