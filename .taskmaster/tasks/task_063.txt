# Task ID: 63
# Title: Implement Whitelist-Based Image Format Validation for Drag-and-Drop Functionality
# Status: pending
# Dependencies: 30, 61
# Priority: medium
# Description: Improve file type validation for drag-and-drop image handling in monochromifier and crude-collage-painter apps by replacing the current broad check with a specific whitelist-based validation to ensure only supported image formats are accepted.
# Details:
1. Analyze current file type validation:
   - Current implementation uses `file.type === 'image'` which accepts broadly any image type
   - p5.js loadImage() doesn't support all image formats (e.g., .jp2)
   - Need to implement stricter validation to prevent errors

2. Implement whitelist-based validation:
   ```javascript
   function validateImageFile(file) {
     const supportedTypes = [
       'image/jpeg', 
       'image/png', 
       'image/gif', 
       'image/webp', 
       'image/bmp', 
       'image/tiff'
     ];
     
     // Check MIME type
     if (!supportedTypes.includes(file.type)) {
       return {
         valid: false,
         message: 'Unsupported file type. Please use JPG, PNG, GIF, WebP, BMP, or TIFF.'
       };
     }
     
     // Additional validation for extension
     const fileName = file.name.toLowerCase();
     const supportedExtensions = ['.jpg', '.jpeg', '.png', '.gif', '.webp', '.bmp', '.tiff', '.tif'];
     const hasValidExtension = supportedExtensions.some(ext => fileName.endsWith(ext));
     
     if (!hasValidExtension) {
       return {
         valid: false,
         message: 'Unsupported file extension. Please use JPG, PNG, GIF, WebP, BMP, or TIFF.'
       };
     }
     
     return { valid: true };
   }
   ```

3. Update the drag-and-drop handlers in affected applications:
   - Modify monochromifier app:
   ```javascript

     const validation = validateImageFile(file);
     
     if (!validation.valid) {
   ```

4. Implement user feedback for invalid files:
   - Add visual error messages when invalid files are dropped
   - Include guidance on supported file types
   - Consider implementing a helper tooltip or info icon that shows supported formats
