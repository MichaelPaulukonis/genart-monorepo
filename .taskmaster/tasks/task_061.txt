# Description: Resolve the inconsistency between the on-screen display and exported images in the monochromifier app, ensuring exported images maintain the same format (square, visible area, etc.) as what users see on screen.
# Details:
1. Architectural clarification (completed):
   - `displayLayer` is the high-resolution (2000x2000) export layer, not the display layer as previously thought
   - The main p5 canvas (600x600) shows a scaled-down version of displayLayer
   - The issue was that transparency mode was recreating image processing instead of using the already-processed displayLayer

2. Solution implemented:
   ```javascript
   function saveCurrentImage() {
     // Always use displayLayer as the base for export (maintains 2000x2000 resolution)
     let exportLayer;
     
     if (!transparencyMode) {
       // For standard mode: return displayLayer directly
       exportLayer = displayLayer;
     } else {
       // For transparency mode: create a copy and apply transparency processing
       exportLayer = createGraphics(outputSize, outputSize);
       // Apply necessary transparency processing to the copy
       exportLayer.copy(displayLayer, 0, 0, outputSize, outputSize, 0, 0, outputSize, outputSize);
       // Apply any additional transparency-specific processing
     }
     
     saveCanvas(exportLayer, 'monochrome-creation', 'png');
   }
   ```

3. Key improvements:
   - Exports are now 2000x2000 pixels (outputSize x outputSize) as intended
   - Exported images match the on-screen display exactly in content and formatting
   - All transformations, zoom, paint strokes, etc. are preserved
   - Both transparency and standard modes work consistently
