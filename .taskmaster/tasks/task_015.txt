# Title: Convert p5.js Apps from Global Mode to Instance Mode
# Status: pending

# Description: Convert four p5.js applications (duo-chrome, crude-collage-painter, those-shape-things, computational-collage) from global mode to instance mode using p5js-wrapper for better encapsulation and code organization.
# Details:
This task involves converting four p5.js applications from global mode to instance mode using the p5js-wrapper library. The conversion will follow these steps for each application:

1. **Import p5 from p5js-wrapper**:
   ```javascript
   // For single sketch pattern
   import { p5 } from 'p5js-wrapper';
   // OR for multi-sketch pattern if needed
   import { createSketch } from 'p5js-wrapper';
   ```

2. **Wrap sketch code in a closure function**:
   ```javascript
   // From:
   function setup() {
     createCanvas(800, 600);
   }
   
   // To:
   const sketch = (p) => {
     p.setup = function() {
       p.createCanvas(800, 600);
     }
   };
   
   new p5(sketch);
   ```

3. **Prefix ALL p5.js functions, variables, and properties with 'p.'**:
   - Convert `createCanvas()` to `p.createCanvas()`
   - Convert `mouseX` to `p.mouseX`
   - Convert `random()` to `p.random()`
   - Convert `color()` to `p.color()`
   - etc.

4. **Convert lifecycle functions to properties of the p5 instance**:
   ```javascript
   // From:
   function setup() { /* ... */ }
   function draw() { /* ... */ }
   function mousePressed() { /* ... */ }
   
   // To:
   p.setup = function() { /* ... */ }
   p.draw = function() { /* ... */ }
   p.mousePressed = function() { /* ... */ }
   ```

5. **Ensure proper variable scoping**:
   - Instance-specific variables should be declared inside the closure
   - Truly global variables (shared across instances) should be outside

6. **Use dragline as a reference implementation** since it already uses instance mode.

For each app, follow these specific implementation steps:

a. **duo-chrome**:
   - Identify all p5.js functions and variables
   - Convert the main sketch file to instance mode
   - Update any event handlers to use the p5 instance
   - Test color cycling and background toggle functionality

b. **crude-collage-painter**:
   - Convert the main sketch and any supporting classes
   - Ensure all DOM manipulation uses the p5 instance
   - Test all painting and collage functionality

c. **those-shape-things**:
   - Convert the main sketch and any shape-generating functions
   - Update the background toggle functionality
   - Test shape generation and interaction

d. **computational-collage**:
   - Convert the main sketch and composition modes
   - Ensure all keyboard handlers use the p5 instance
   - Test all composition modes and save functionality

Reference the following documentation:
- docs/libs/p5js_wrapper_context.xml
