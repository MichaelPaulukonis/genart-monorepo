# Description: Create a toggleable overlay that displays keyboard controls and usage instructions for the duo-chrome app, similar to dragline's info box.
# Details:
Implement an on-screen help display for the duo-chrome app that shows available keyboard controls and usage instructions:

1. Create a new HTML element for the help overlay:
   ```html
   <div id="help-overlay" class="help-overlay hidden">
     <div class="help-content">
       <h2>Duo-Chrome Controls</h2>
       <ul>
         <li><strong>Mouse Click</strong>: Generate new image</li>
         <li><strong>B</strong>: Toggle background</li>
         <li><strong>C</strong>: Toggle color cycling</li>
         <li><strong>M</strong>: Cycle through blend modes</li>
         <li><strong>P</strong>: Pause/resume animation</li>
         <li><strong>S</strong>: Toggle auto-save</li>
         <li><strong>Cmd+S</strong>: Manual save</li>
         <li><strong>H/I</strong>: Toggle this help display</li>
       </ul>
     </div>
   </div>
   ```

2. Add CSS styling for the help overlay:
   ```css
   .help-overlay {
     position: absolute;
     top: 0;
     left: 0;
     width: 100%;
     height: 100%;
     background-color: rgba(0, 0, 0, 0.7);
     display: flex;
     justify-content: center;
     align-items: center;
     z-index: 1000;
   }
   
   .help-content {
     background-color: rgba(255, 255, 255, 0.9);
     padding: 20px;
     border-radius: 8px;
     max-width: 400px;
     color: #333;
   }
   
   .hidden {
     display: none;
   }
   ```

3. Implement JavaScript to toggle the help display:
   ```javascript
   // Add event listener for 'h' and 'i' keys to toggle help
   document.addEventListener('keydown', function(event) {
     if (event.key === 'h' || event.key === 'i') {
       const helpOverlay = document.getElementById('help-overlay');
       helpOverlay.classList.toggle('hidden');
     }
   });
   ```

4. Ensure the help overlay is initially hidden when the app loads.

5. Test the implementation with all keyboard shortcuts to verify they work as expected.

6. Make sure the help overlay is responsive and displays correctly on different screen sizes.

7. Consider adding a small help icon (?) in a corner of the app that can also toggle the help display for users who may not know the keyboard shortcut.
