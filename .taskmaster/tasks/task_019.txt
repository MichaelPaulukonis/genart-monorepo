     ```typescript
     test('can draw on canvas with mouse', async ({ page }) => {
       await page.goto('/');
       await page.waitForSelector('canvas');
       
       // Get canvas position and dimensions
       const canvasBounds = await page.evaluate(() => {
         const canvas = document.querySelector('canvas');
         const rect = canvas.getBoundingClientRect();
         return { x: rect.x, y: rect.y, width: rect.width, height: rect.height };
       });
       
       // Perform drawing operation
       await page.mouse.move(canvasBounds.x + 100, canvasBounds.y + 100);
       await page.mouse.down();
       await page.mouse.move(canvasBounds.x + 200, canvasBounds.y + 200, { steps: 10 });
       await page.mouse.up();
       
       // Take screenshot to verify drawing occurred
       expect(await page.screenshot({ 
         fullPage: false,
         clip: { x: 0, y: 0, width: 800, height: 600 }
       })).toMatchSnapshot('after-drawing.png');
     });
     ```

# Test Strategy:
The test strategy will verify that the Playwright test suites are comprehensive and effective:

1. **Test Coverage Verification**:

2. **Visual Regression Testing**:
   - Verify baseline screenshots are captured for all key states
   - Run tests multiple times to ensure consistency in visual comparisons
   - Check that screenshot comparisons correctly identify visual changes

3. **Functionality Testing**:
   - For crude-collage-painter:
     - Verify tests for drawing functionality work correctly
     - Confirm mode switching tests properly validate state changes
     - Ensure image loading tests validate both file upload and drag-drop
     - Check that save functionality tests confirm proper file generation
   
   - For computational-collage:
     - Verify tests for all composition modes (0-9) work correctly
     - Confirm gallery view tests validate image display and selection
     - Ensure keyboard shortcut tests cover all documented shortcuts
     - Check that UI control tests validate all Tweakpane interactions

4. **Edge Case Testing**:
   - Verify tests handle error conditions gracefully

   - Check that tests validate behavior with invalid inputs

5. **Test Reliability**:
   - Run tests in sequence and in parallel to verify stability

   - Ensure tests are deterministic and produce consistent results

6. **Pre-Conversion Baseline**:

7. **Documentation Review**:

8. **CI Integration Testing**:
