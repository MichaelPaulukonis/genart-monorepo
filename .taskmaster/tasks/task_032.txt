# Status: in-progress
# Dependencies: 28
# Priority: medium
# Description: Implement URL-based composition sharing for the duo-chrome app that encodes the current composition state into URL parameters, allows restoring compositions from URL parameters, and provides convenient sharing features for users to share their curated compositions.
# Details:
Create a robust URL-based state sharing system for the duo-chrome app to enable easy sharing and bookmarking of curated compositions. The implementation should include:

1. **State Serialization**:
   - Encode the current app state (image indices, colors, scales, blend modes, background modes) into URL parameters
   - Example URL structure: `?imageA=42&imageB=156&colorA=riso-red&colorB=riso-blue&scaleA=1.2&scaleB=0.8&blendMode=1&bgMode=0`
   - Ensure encoding is compact but human-readable when possible

2. **State Restoration**:
   - On page load, parse URL parameters using `URLSearchParams`
   - Restore composition state from parameters if present
   - Gracefully handle missing or invalid parameters with sensible defaults

3. **Share Functionality**:
   - Add a share button to the UI and/or keyboard shortcut (e.g., Shift+S)
   - Only update the URL when the share button is clicked to avoid performance overhead
   - Consider implementing native Web Share API support where available
   - Add visual feedback (toast notification, modal, etc.) when a link is generated

4. **User Experience**:
   - Provide clear indicators when a composition has been loaded from URL parameters
   - Add copy-to-clipboard functionality for easier sharing
   - Consider shortened URL options for very complex compositions
   - Auto-pause feature when loading shared compositions to preserve the intended state

5. **Maintainability & Future-Proofing**:
   - Design the parameter schema to be extensible for future composition parameters
   - Add version parameter to URL to handle potential future breaking changes to parameter encoding
   - Document the URL parameter schema for future reference

# Test Strategy:
1. **State Serialization Testing**:
   - Verify that all relevant composition parameters are correctly encoded in the URL
   - Test encoding of edge case values (very large/small numbers, special characters in color names)
   - Ensure URL length stays reasonable for typical compositions

2. **State Restoration Testing**:
   - Test loading the app with various URL parameter combinations
   - Verify the composition is exactly reproduced from URL parameters
   - Test with missing or partial parameters and confirm graceful fallbacks
   - Test with invalid parameters and verify error handling

3. **Share Functionality Testing**:
   - Test share button/shortcut creates a correct URL with current state
   - Verify copy-to-clipboard functionality works across browsers
   - Test share workflows on mobile and desktop devices

4. **Cross-Browser & Platform Testing**:
   - Share URLs between different browsers and verify compositions render identically
   - Test URL sharing between desktop and mobile devices
   - Verify long URLs are handled correctly across platforms

5. **Performance Testing**:
   - Confirm URL updates only happen on explicit share actions
   - Verify parsing URL parameters on load doesn't significantly impact startup time

6. **Regression Testing**:
   - Ensure existing app functionality is not affected by the URL parameter system
