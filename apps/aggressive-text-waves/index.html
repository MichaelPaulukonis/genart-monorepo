Aggressive Text Waves

Words drift across a noise field, pulled by wandering gravity sources using boids-style physics.

Controls

  • Space — Pause / resume
  • n — Step one frame (when paused)
  • c — Toggle gravity center indicators
  • o — Toggle word outlines
  • s — Save current frame as PNG
  • r — Toggle frame recording (sequential PNGs)
  • ? — Show/hide this screen
  • Esc — Close this screen

Use the Tweakpane panel (top-right) to adjust scale, gravity, and physics parameters.
