Duo-Chrome Controls

Interactive Image Composition

Image Selection

  • A - Select Image A for control
  • B - Select Image B for control
  • X - Exchange images A and B

Image Navigation

  • ← / → - Navigate images (or History if Filmstrip active)
  • Cmd+[ / Cmd+] - Cycle colors in palette
  • Mouse Click - Generate new pair

Size Control

  • ↑ / ↓ - Adjust active image size

Visual Effects

  • B - Toggle background color
  • C - Cycle color palettes
  • M - Cycle blend modes

Display & Feedback

  • V - Toggle visual indicators
  • I - Toggle status display
  • L - Filter Images

History Navigation

  • [ or ← - Previous composition
  • ] or → - Next composition
  • Shift+[ - Previous 10 compositions
  • Shift+] - Next 10 compositions
  • Cmd+[ - Jump to beginning
  • Cmd+] - Jump to end
  • F - Toggle filmstrip
  • Shift+C - Clear history
  • Shift+T - Regenerate thumbnails

Animation & Save

  • P / Space - Pause/resume
  • S - Toggle auto-save
  • Cmd+S - Manual save
  • Shift+S - Share composition (copy URL)

Help

  • H or ? - Toggle this help
