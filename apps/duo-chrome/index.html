Analog Video Synthesizer

Channel Select

  • A — Select Image A
  • B — Select Image B
  • X — Exchange A and B

Image Navigation

  • ← / → — Navigate images
  • Shift+← / Shift+→ — History ±10
  • Cmd+← / Cmd+→ — History start/end
  • Mouse Click — Generate new pair

Size Control

  • ↑ / ↓ — Adjust active image size

Signal Effects

  • C — Cycle color palettes
  • G — Open palette picker
  • M — Cycle blend modes
  • V — Toggle visual indicators

Transport

  • P / Space — Play / Pause loop
  • , / . — Step one frame
  • < / > — Step five frames

Display

  • I — Toggle Monitor module
  • F — Toggle Filmstrip
  • L — Open Contact Sheet

History

  • [ or ← — Previous composition
  • ] or → — Next composition
  • Shift+C — Clear history
  • Shift+T — Regenerate thumbnails

Save & Share

  • S — Toggle auto-save
  • Cmd+S — Manual save
  • Shift+S — Copy share URL

Help

  • H or ? — Toggle this help
