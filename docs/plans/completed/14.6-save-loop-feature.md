# Task 14.6 - Save Loop Feature Implementation

**Status**: Implemented  
**Date**: 2026-01-25  
**Related**: Task 14 - Loop Animation Mode

## Overview

Implemented the "Save Loop" feature that exports all frames of a complete loop animation as individual PNG files. This allows users to create GIFs or videos externally from the saved frames.

## Problem Statement

Users need a way to export all frames from a loop animation as individual images so they can:
- Create animated GIFs externally
- Edit frames individually
- Create video compositions
- Archive specific loop sequences

The feature must be separate from the Play/Pause preview functionality and should not interfere with normal playback operations.

## Requirements

1. **Export Format**: Individual PNG files for each frame
2. **Naming Convention**: `loop-{timestamp}-frame-{001...N}.png`
3. **Timestamp**: Single datetime stamp for entire sequence (initialized at start)
4. **Progress Feedback**: Use existing frame counter to show save progress
5. **Interruption**: Disable Save button while saving, but Stop button can interrupt
6. **Enable Conditions**: Button enabled only when walk exists and playback is paused/stopped
7. **Integration**: Wrap around existing `p.saveCanvas(generateFilename())` mechanism

## Technical Implementation

### 1. Loop Animation Controller (`loop-animation-controller.js`)

Added three new methods:

#### `saveLoop(saveFrameCallback, onProgress)`
- Iterates through all frames in the walk
- Calls the save callback for each frame
- Reports progress via callback
- Handles interruption via `isSavingLoop` flag
- Automatically pauses playback during save
- Resumes playback after save if it was playing before

```javascript
async saveLoop (saveFrameCallback, onProgress = () => {}) {
  if (!this.walk || this.walk.length === 0) {
    throw new Error('No walk to save')
  }

  this.isSavingLoop = true
  const wasPlaying = this.isPlaying
  
  if (wasPlaying) {
    this.pause()
  }

  try {
    for (let i = 0; i < this.walk.length; i++) {
      if (!this.isSavingLoop) {
        console.log('[LoopAnimation] Save interrupted at frame', i)
        break
      }

      this.currentFrameIndex = i
      const frame = this.getCurrentFrame()
      this.onFrameChange(frame)

      onProgress(i + 1, this.walk.length)
      await saveFrameCallback(i, frame)
      await new Promise(resolve => setTimeout(resolve, 100))
    }

    console.log('[LoopAnimation] Save complete')
  } finally {
    this.isSavingLoop = false
    
    if (wasPlaying) {
      this.play()
    }
  }
}
```

#### `interruptSave()`
- Sets `isSavingLoop` flag to false
- Allows Stop button to interrupt ongoing save operations

#### Updated `destroy()`
- Now calls `interruptSave()` to clean up any ongoing save operations

#### Updated `getAnimationInfo()`
- Added `savingLoop` property to animation info

#### `handleSaveLoop()` Method
- Validates walk exists
- Generates single timestamp for all frames
- Calls controller's `saveLoop()` with callbacks
- Updates progress using frame counter
- Handles errors gracefully

```javascript
async handleSaveLoop() {
  if (!this.controller.walk || this.controller.walk.length === 0) {
    console.warn('[LoopPanel] No walk to save')
    return
  }

  if (this.controller.isSavingLoop) {
    console.warn('[LoopPanel] Save already in progress')
    return
  }

  console.log('[LoopPanel] Starting loop save...')
  
  const timestamp = new Date().toISOString().replace(/[:.]/g, '-').slice(0, 19)
  
  try {
    await this.controller.saveLoop(
      async (frameIndex, frame) => {
        if (this.callbacks.onSaveFrame) {
          const filename = `loop-${timestamp}-frame-${(frameIndex + 1).toString().padStart(3, '0')}`
          console.log(`[LoopPanel] Saving frame ${frameIndex + 1}/${this.controller.walk.length}: ${filename}`)
          await this.callbacks.onSaveFrame(filename)
        }
      },
      (current, total) => {
        console.log(`[LoopPanel] Progress: ${current}/${total}`)
        this.updateFrame()
        this.updatePlaybackButtons()
      }
    )
    
    console.log('[LoopPanel] Loop save complete')
  } catch (error) {
    console.error('[LoopPanel] Error saving loop:', error)
  } finally {
    this.updatePlaybackButtons()
  }
}
```

#### `updatePlaybackButtons()` Enhancement

if (this.elements.saveLoopBtn) {

## Usage Flow

1. **Enable Loop Mode**: User toggles loop mode on
2. **Generate Walk**: User sets loop length and generates the walk sequence
3. **Preview (Optional)**: User can preview the loop with Play/Pause
4. **Save Loop**: User clicks "💾 Save Loop" button
5. **Progress**: Frame counter updates showing "Frame X/Y" as saves progress
6. **Interrupt (Optional)**: User can click Stop to cancel the save operation
7. **Completion**: All frames saved as `loop-{timestamp}-frame-001.png`, `loop-{timestamp}-frame-002.png`, etc.

## Known Limitations

1. **Browser Download Limitations**: Browsers may prompt for permission when saving multiple files
2. **Performance**: Large loops (>100 frames) may take time to save
3. **No Merge**: Files are not automatically merged into GIF/video (external tools required)
4. **No Batch Naming Options**: Filename pattern is fixed
